# LitigationOS marketing site with Google Sheet form

Upload this complete folder to the GitHub repository used for `www.litigationos.in`.

The firm-demo form is already connected to the Google Apps Script web app supplied by the owner. It sends these fields to the Google Sheet: name, email, firm, role, message and source.

The Create account buttons open `https://app.litigationos.in/`.

After uploading, ensure `assets/litigationos-mark.png` is also in the repository. Commit the change and Vercel will deploy it automatically.
